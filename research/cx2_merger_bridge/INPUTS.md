# Prospective normalized evidence contract

Run from `research/` with `.venv/bin/python -m cx2_merger_bridge.run --inputs cx2_merger_bridge/.cache/normalized`. The default command without `--inputs` regenerates the feasibility audit only. All inputs must live inside this study's owned folders. No live trade, recurring task or recorder change is authorized.

`deals.json` is a list of `engine.Deal` records. Required identity/time fields are deal_id, agreement_id, entry, deadline and put_expiry (all times with UTC offsets). Include cash_offer, strike, exactly 20 preannouncement_closes, and prior20_share_volume. Entry stock/event/put quotes each contain bid, ask, timestamp, bid_size, ask_size and source. Event quotes must be the No token for the exact buyer/target agreement. Put prices are per underlying share; option size is contracts. Event sizes are tokens; stock sizes are target shares. Use raw historical NBBO/book snapshots and cite their archive locations. Store event_entry_fee_per_token and event_exit_fee_per_token as verified dollar fees at the actual quote prices, not a current rate guessed backward in time.

All required proof flags must be true only with source documents: completion_contract, exact_agreement, signed_cash_deal, rule_known_asof, deliverable_verified, entry_clock_verified. `evidence_urls` must identify the signed announcement and time, exact versioned contract text, actual historical option chain (the first standard expiry after deadline and the strike nearest the 80% reference with lower-strike tie-break), OCC deliverable, and execution snapshots. The entry_clock_verified evidence must establish the frozen 15:45 New York entry at least one full trading session after the announcement. The evaluator refuses missing/stale/future/crossed quotes but cannot independently authenticate a source citation or a manually certified flag. Never mark synthetic inputs as verified evidence.

`marks.csv` has one row for every regular equity trading session from entry through the frozen exit, keyed by deal_id. Columns: date (UTC-offset timestamp), stock_value (dollars/share), event_value (dollars/No token), put_value (dollars/underlying-share), dividend_per_share (cash paid that session), stock_exit_cost, event_exit_cost, put_exit_cost, source, terminal_evidence_verified (boolean). Values are midpoint marks while a leg is active and actual cash values once it settles. Each exit cost is the total observed half-spread plus fees/commissions **per one stock lot**, applied only on the final row. A 2x stress doubles those measured costs. A settled leg must retain its cash value until final portfolio close; do not omit assets or infer its cash value from another leg. Terminal_evidence_verified must be true only if independent stock/event/option exits or cash settlements and depth are supported. If a completion contract pays No after a late close, retain both the target cash and the event cash. Enter a documented revised cash consideration as its actual value. A termination before the deadline does not settle an event automatically unless its own rules say so.

`calendar.csv` has date for all regular trading sessions in the study window, including sessions without active deals. The evaluator refuses missing active marks and funding above starting capital. It uses common target exposure for all three portfolios and leaves unused comparator capital in cash. Up to ten simultaneous deals use $10,000 allocations each; prices, lot rounding and the 1% depth/volume cap determine deployed capital. Cash pays zero interest; borrowing is refused, so funding interest is zero in this conservative implementation.

The evaluator supplies NAV, net terminal P&L, daily returns, Sharpe, drawdown, worst month a deal-cluster bootstrap and a five-session block bootstrap. It does not create missing historical fills. Its current small-sample flags and chronological 20% split are necessary checks, not automatic proof of the full success criterion in METHOD.md. A supported sample still needs a manual source/depth audit, entry-date clustering across simultaneously entered deals, recent exposure-matched inference, a full concentration/tail/month/turnover/capacity report and a check of any Sharpe above 3 before a positive result can be claimed.

Optional marks columns named `event_hedge_traded_dollars_per_lot`, `unhedged_traded_dollars_per_lot` and `put_hedge_traded_dollars_per_lot` contain actual gross executed dollar volume by session and unit lot. Settlement cash is excluded. If these are absent, turnover is missing rather than assumed to be twice the initial purchase.
